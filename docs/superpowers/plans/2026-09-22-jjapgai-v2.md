# 짭가이 v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 배포 중인 짭가이(단일 스테이지 슈팅)에 탄 단계 상쇄, 캐릭터 3명 선택, 30 스테이지 3막 구성, 전용 보스 3종, 보스 체크포인트를 추가한다.

**Architecture:** `frontend/index.html` 단일 파일을 계속 쓴다. 상수 → 스프라이트 → 상태 → 입력 → 발사 → 스텝 → 렌더 → 루프의 블록 구조와 고정 타임스텝 누산기는 그대로 유지하고, 그 안에서 (1) 탄에 `tier` 필드를 추가해 상쇄 패스를 하나 넣고, (2) 하드코딩된 발사 함수를 `CHARS` 데이터 테이블로 바꾸고, (3) 단일 `WAVES` 배열을 패턴 라이브러리 + 절차적 `buildStage(s)` 로 대체하고, (4) 단일 `BOSS` 를 `BOSSES` 3종 + 공통 프레임워크로 분리하고, (5) `localStorage` 체크포인트를 붙인다.

**Tech Stack:** HTML5 Canvas 2D, vanilla ES2020 (외부 라이브러리 0개), 검증용 playwright-core 1.63.0 (레포 외부)

**Spec:** `docs/superpowers/specs/2026-09-22-jjapgai-v2-design.md` (v1 spec `2026-09-21-tengai-shmup-design.md` 의 상수·규칙은 v2가 덮어쓰지 않는 한 유효)

- **고정 타임스텝 루프(블록 10의 `frame`/누산기)와 캔버스 설정(블록 2)의 구조를 바꾸지 말 것.** `fitCanvas` 의 `raw >= 1 ? Math.floor(raw) : raw` 분기는 좁은 뷰포트 클리핑 수정이므로 되돌리지 말 것.

- [ ] **Step 3: 블록 8에 `cancelBullets()` 추가**

`hitPlayer()` 정의 **뒤**에 넣는다.

```js
  // 탄 단계 상쇄. 최솟값 차감이므로 같은 단계면 둘 다 소멸하고, 다르면 낮은 쪽만
  // 소멸하면서 높은 쪽의 단계를 깎는다.
  // 비용은 O(내 탄 x 적 탄). 최악 20x40 = 800회/프레임 = 48k회/초로 JS에서 무시할
  // 수준이라 공간 분할을 넣지 않는다.
  function cancelBullets() {
    for (let i = pbullets.length - 1; i >= 0; i--) {
      const p = pbullets[i];
      for (let j = ebullets.length - 1; j >= 0; j--) {
        const e = ebullets[j];
        if (!overlaps(p, e)) continue;
        const m = Math.min(p.tier, e.tier);
        p.tier -= m;
        e.tier -= m;
        if (e.tier <= 0) {
          ebullets.splice(j, 1);
          game.score += 10;
          game.cancels += 1;
        }
        if (p.tier <= 0) { pbullets.splice(i, 1); break; }
      }
    }
  }
```

바깥 루프도 역순인 이유: 안쪽에서 `pbullets.splice(i, 1)` 후 `break` 하므로 바깥 인덱스가 뒤로 밀리면 안 된다.

- [ ] **Step 4: `step(dt)` 에 배선**

- [ ] **Step 5: 관통탄 렌더에 단계 피드백**

`render()` 의 pbullets 루프에서 관통탄 폭을 남은 단계에 비례시킨다. 상쇄로 단계가 깎인 봉황이 눈에 보이게 줄어들어야 플레이어가 시스템을 읽을 수 있다.

```js
    for (const b of pbullets) {
      const bw = b.pierce ? Math.max(6, Math.round(PHOENIX_W * (b.tier / 3))) : b.w;
      if (b.pierce) {
```

`b.w` 는 충돌 판정용이므로 **바꾸지 않는다** — 렌더 폭만 줄인다. 판정까지 줄이면 "보이는 것보다 넓게 맞는" 문제가 생기지만, 관통탄은 플레이어에게 유리한 쪽이라 이 비대칭은 의도된 것이다.

```js
  // 진행 보존. localStorage는 프라이빗 모드, file:// 스킴, 용량 초과로 던질 수
  // 있다. 전부 try/catch로 감싸고 실패 시 메모리 폴백으로 동작한다 — 저장이 안
  // 될 뿐 게임은 정상 진행해야 하고, 저장 실패를 사용자에게 알리지 않는다.
  const PROGRESS_KEY = "jjapgai.progress";
  let memoryAct = 1;

  function loadProgress() {
    try {
      const raw = localStorage.getItem(PROGRESS_KEY);
      if (!raw) return memoryAct;
      const v = JSON.parse(raw);
      const a = Number(v && v.act);
      return a >= 1 && a <= 3 ? Math.floor(a) : memoryAct;
    } catch (_) {
      return memoryAct;
    }
  }

  function saveProgress(act) {
    memoryAct = Math.max(memoryAct, act);
    try {
      localStorage.setItem(PROGRESS_KEY, JSON.stringify({ act: memoryAct }));
    } catch (_) { /* 메모리 폴백으로 충분하다 */ }
  }
```
